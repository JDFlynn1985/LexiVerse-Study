Developer SDK Manual

LexiVerse follows a Unified Native Architecture. Research modules are not isolated sub-apps but integrated components of the core engine.

Core Directories

The project is structured to separate intelligence from interface while maintaining high-performance reactivity.

src/ai/flows/    // The intelligence layer
src/components/views/ // The UI layer (Memoized)
src/firebase/    // The data layer (RBAC)
src/lib/         // Utilities (RAG, Sanitization)

Developing AI Flows

All AI logic MUST use the global ai instance from @/ai/genkit.

  • Pattern: Define a Prompt, wrap it in a Flow, and export a server wrapper.
  • Grounding: Always prefer the searchBibleVerse tool for scripture analysis.

Sanitization Policy

Security is paramount in scholarly environments. Every user-controllable text field MUST be sanitized.

import { sanitizeHtml } from '@/lib/sanitization';
const cleanInput = sanitizeHtml(userInput);
