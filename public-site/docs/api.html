API Reference (v1.1)

The LexiVerse API allows external scholarly tools to leverage our research engine and grounded data sets. Version 1.1 introduces dedicated linguistic and synoptic endpoints.

Authentication

All requests must include a Bearer token in the Authorization header. Tokens can be generated in the API Portal.

Authorization: Bearer lv_...

Available Endpoints

1. POST /api/v1/research

Executes a synthesized scholarly analysis query, optionally grounded in RAG context.

2. GET /api/v1/lexicon

Retrieves verified linguistic data for a Strong's Number (e.g., ?number=G3056).

3. POST /api/v1/synoptic

Maps a biblical event across the four Gospel traditions for comparative tradition analysis.
