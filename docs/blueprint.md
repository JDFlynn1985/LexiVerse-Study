# **App Name**: LexiVerse Explorer

## Core Features:

- Scripture Word Lookup: Search for Greek, Hebrew, and Aramaic terms with definitions, lexical data, transliteration, and pronunciation, integrating data from BlueLetterBible.com and the YouVersion API.
- Root Word Tracing: Trace word roots and their definitions, and lexical data, supporting Aramaic roots.
- Commentary and Contextual Search: Search online commentaries for historical and linguistic context of words and their roots. This tool will gather insights from various sources.
- Verse Reference Integration: Fetch complete verses for word references and provide lists of cross-references between passages using node-sword-interface and Bible-get-node.
- Multi-Version Translation Comparison: Research how a word is translated across various Bible versions.
- AI-Powered Study Assistant: Utilize Brain.js to provide AI-driven insights and combine information from all sources into a cohesive, academically structured response with full bibliographies, tailored for seminary students.
- Offline Mode and Caching: Provide an offline mode with data storage caching for continuous access.
- Sword Module Management: Interface to download, install, and manage available Sword modules, enabling comprehensive Bible study beyond word studies.
- Voice Input: Enable voice input for searches and interactions using Whisper.js.

## Style Guidelines:

- Color Scheme: A harmonious blend inspired by ancient manuscripts and illuminated texts. Primary color: Deep Indigo (#301934) for depth and scholarship. Background color: Desaturated parchment (#F5F5DC) for a warm, classic feel. Accent color: Muted Gold (#DAA520) for highlights and important information, evoking ancient artifacts.
- Font Pairing: 'Literata' (serif) for headlines to convey a scholarly and literary tone, and 'Inter' (sans-serif) for body text for clarity and readability in longer passages.
- Use of stylized icons reminiscent of ancient script elements and biblical symbols. For example, a scroll for 'Search', an open book for 'Commentaries', and a quill for 'Export'.
- A clean, modern PWA layout that feels like a digital study desk. Emphasis on organized information hierarchy, with expandable sections for detailed data, root analysis, and commentary insights. Desktop app version should adapt to a multi-pane view similar to advanced research software.
- Subtle and purposeful animations. Fade-ins for loaded content, smooth transitions between sections, and elegant loading indicators that evoke the unfolding of knowledge.
