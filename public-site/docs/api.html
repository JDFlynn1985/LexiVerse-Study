API Reference (v1)

External scholarly tools and institutional scripts can integrate with the LexiVerse research engine using our RESTful API.

Authentication

All requests must include a Bearer token in the Authorization header. Tokens can be generated in the API Portal.

Authorization: Bearer lv_...

Primary Endpoint

POST /api/v1/research

Executes a synthesized scholarly analysis query, optionally grounded in RAG context.

Tiered Rate Limits

  • Basic: 20 queries / 24 hrs.
  • Scholar: 100 queries / 24 hrs.
  • Institution: 5000 queries / 24 hrs.
