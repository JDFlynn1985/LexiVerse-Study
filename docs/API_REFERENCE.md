# LexiVerse API Reference (v1.2)

External scholarly tools and institutional scripts can integrate with the LexiVerse AI engine and RAG context using the versioned RESTful API.

## 🔐 Authentication & Eligibility
All requests must include a Bearer token in the `Authorization` header. Tokens can be generated by researchers in the **API Portal** (`/api-keys`).
- **Format**: `Authorization: Bearer lv_...`
- **Eligibility**: Token generation is restricted to scholars who have verified compliance with **Clause 1.1 (15+ age requirement)** during account registration.

## 📉 Tiered Rate Limits
Access is governed by institutional tiers managed in the System Settings:
- **Basic**: 20 queries / 24 hours.
- **Scholar**: 100 queries / 24 hours.
- **Institution**: 5000 queries / 24 hours.

## 📡 Endpoints

### 1. POST `/api/v1/research`
Executes a synthesized scholarly analysis query, grounded in the platform's AI engine and optional RAG context.

**Request Body**:
```json
{
  "term": "Genesis 1:1",
  "researchContext": [
    "Excerpt from local institutional paper...",
    "Secondary source fragment..."
  ]
}
```

**Response**:
Returns a `ResearchOutput` object containing `originalWord`, `aiInsights`, `verseUsages`, and an SBL-style `bibliography`.

### 2. GET `/api/v1/lexicon`
Retrieves verified linguistic data for a specific Strong's Number.

**Parameters**:
- `number` (query): The Strong's identifier (e.g., `G3056`).

**Response**:
Returns a `LexiconOutput` object containing the original alphabet, transliteration, morphology, and verified definition.

### 3. POST `/api/v1/synoptic`
Maps a biblical event across the four Gospel traditions for comparative exegesis.

**Request Body**:
```json
{
  "event": "The Transfiguration"
}
```

**Response**:
Returns a `SynopticOutput` aligning references from Matthew, Mark, Luke, and John with AI-synthesized nuances.

## 🛡️ Governance & Sanitization
All API requests are subject to the same sanitization and security policies as the web interface. Malicious script injection or path traversal attempts will result in immediate 403 Forbidden responses and administrative flagging.
