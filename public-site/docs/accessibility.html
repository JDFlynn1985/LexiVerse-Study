Accessibility Standards (WCAG 2.1 AA)

LexiVerse Explorer is committed to providing a digitally inclusive environment for all scholars, regardless of physical or cognitive ability.

Core Measures

  • Robust Foundation: Built on Radix UI primitives for keyboard-first navigation and focus management.
  • Visual Clarity: High-contrast "Parchment" theme exceeding 4.5:1 ratio for reduced eye strain.
  • Semantic HTML: Standard landmarks (header, nav, main) for screen reader efficiency.
  • Interactive Components: Aria-live announcements for urgent feedback and error logging.
