Technical Stack & Infrastructure

LexiVerse is built on a modern, scholarly-focused architecture that prioritizes performance and local-first privacy.

Core Frameworks

  • Next.js 15: App Router and Server Actions.
  • React 19: Declarative modular UI.
  • Firebase 11: Firestore NoSQL & Google OIDC.
  • Genkit 1.x: AI orchestration layer.

AI Engines

  • Google Gemini: Primary reasoning engine.
  • Ollama: On-premise air-gapped support.

Libraries

  • PDF.js: Local PDF parsing for RAG.
  • Radix UI: Accessible primitives.
  • Recharts: Theological influence mapping.
