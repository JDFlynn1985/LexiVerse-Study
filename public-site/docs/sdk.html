Developer SDK Manual (v1.2)

LexiVerse follows a Unified Native Architecture. Research modules are integrated components of the core engine, now featuring Grounded Intelligence for academic precision.

Core Directories

The project separates intelligence, infrastructure, and interface to maintain high performance.

src/ai/flows/    // Intelligence Layer (Genkit)
src/app/actions/ // Infrastructure Layer (Server Actions)
src/components/views/ // UI Layer (Memoized React)
src/firebase/    // Data Layer (RBAC & Sync)
src/lib/         // Utility Layer (RAG & Sanitization)

Grounded AI Patterns

All AI logic MUST utilize Grounded Tool Calling to prevent hallucinations. The engine is instructed to fetch primary lexical and commentary data before performing synthesis.

  • fetchStrongsData: Retrieves verified linguistic data.
  • searchBibleVerse: Fetches real-time scripture text.
  • aggregateCommentary: Pulls from historical scholarly works.

Sanitization Policy

Security is paramount. Every user-controllable text field MUST be sanitized using the standardized utilities.

import { sanitizeHtml, sanitizeRichText } from '@/lib/sanitization';
const cleanSearch = sanitizeHtml(userInput);
const cleanWiki = sanitizeRichText(editorContent);

Institutional Integration

Developers must respect UserStudyProfile flags. Access to modern Bible versions and administrative portals is governed by the licensedVersions and isAdmin metadata stored in Firestore.
