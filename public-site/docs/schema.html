Database Schema & Relationships

LexiVerse uses Firebase Firestore for real-time scholarly collaboration and strict role-based access control.

Primary Collections

  • /users/{userId}: Core profile and academic designation.
  • /users/{userId}/sessions: Saved research reports from the AI Hub.
  • /messages/{msgId}: Social discourse stream (global and institutional).
  • /wiki_entries/{entryId}: Peer-reviewed knowledge base articles.
  • /system/config: Global AI environment variables.

Governance Logging

  • /error_logs: Captures runtime exceptions for administrative review.
  • /search_logs: Powers real-time institutional analytics.
  • /dmca_complaints: Formal legal notices for automated takedown events.
